# Contributing

1. Edit files in `src/`. Top-level names must be unique, because `build.py` joins them into one script.
2. Run `python3 build.py` and open `dist/machine-legends.html`.
3. Add both English and Arabic strings for any new text (`S('key', 'English', 'العربية')`).
4. Run a playthrough test from `tests/` before opening a pull request.

Bug reports are welcome: say the browser, the language, and the room you were in.
